最终配色 Demo：五大组决赛版

每一组只保留 1 套最终融合方案。它们都吸收了同组内你之前选中的两个主体，再揉合未入选方案的优点。现在你只需要挑出最适合正式落地到编辑器里的那一套，或者挑 2-3 套作为正式主题。

F1 青墨纸窗和风浅色组
以 青墨染 为骨，以 纸窗清影 为气。保留青绿的安静，又加入纸门透光和轻灰雾感，适合你如果想让编辑器“像一本能久读的册页”。
浅色和风耐看
F2 群青听潮深海夜色组
以 月下群青 为主视觉，以 墨海听潮 的蓝绿呼吸感做平衡。金色点睛但被压得更稳，适合做主深色主题。
深色群青古金
F3 金泥茶烟古风暖色组
以 金泥宴火 的华贵为主，再收一点 琥珀茶烟 的茶棕。灯火感还在，但更克制，更像器物与卷轴，而不是纯“热闹红”。
暖色中式古风贵气
F4 竹岚杉影森林自然组
以 竹露晨青 的鲜活为主，再吸收 杉青寒岚 的压色与克制。相比“森林绿”更轻，比“杉青”更不闷。
森林护眼自然
F5 月白寒川混合实验组
以 月白金 的浅底高级感为主，再借 寒川银 的冷静灰度，让它既不像传统浅色那样发黄，也不像灰色那样没精神。
实验高级感中性
建议你最终给我这样的反馈：
1. 直接选一个：F1 / F2 / F3 / F4 / F5
2. 或者说：以 F2 为主，但按钮颜色换 F3，输入框背景换 F5
3. 如果你想“一个浅色 + 一个深色”并存，那通常建议：F1 + F2 或 F3 + F4
